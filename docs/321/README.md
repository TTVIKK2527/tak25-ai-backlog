# #321: AI backlog'i tööriista arendusplaan

## Eesmärk ja piirid

Projektijuht muudab kliendi idee kasutajalugudeks, seab prioriteedid ning kinnitab vastuvõtukriteeriumid ja mockup'id. AI teeb ettepanekuid; inimene otsustab. Siht on ühe projektijuhi väike veebirakendus, mitte automaatne kliendi nõusoleku asendamine.

See on olemasoleva projekti eraldi kavandamise materjal. Olemasolev kood ei tõenda üksinda #321 õpiväljundeid ega individuaalset kaitsmist. Allpool kirjeldatud protsess ja esimene arendusperiood on kavand, mitte väide toimunud meeskonnatööst.

## Kontrollitavad piirangud

Kohalik diagrammi lähtefail ja dokumendid ei tõenda veel vahendi tegelikku kasutamist: diagramm tuleb diagrams.net-is avada ning muuta. Tööde haldamise keskkonnas tuleb näidata tegelikke töid, mitte ainult Markdown-tabelit. Nende tegevuste tõend ja avaldatud lingid lisatakse pärast päris kontrolli. Kaitsmise sooritamist ega õpetaja vastuvõtmist ei väideta ette.
